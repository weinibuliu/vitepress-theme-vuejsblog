# vitepress-theme-vuejsblog

> [!NOTE]
> 该主题基于 vitepress@2.0.0-alpha.20 开发，不保证对其他版本兼容。

一个基于 [blog.vuejs.org](https://blog.vuejs.org) 风格的 Vitepress 主题。

[Demo](https://weinibuliu.github.io/vitepress-theme-vuejsblog)

[使用引导](https://weinibuliu.github.io/vitepress-theme-vuejsblog/docs/zh-cn/welcome)

## 快速开始

### 从脚手架开始 (推荐)

```bash
pnpm create vitepress-theme-vuejsblog@latest my-blog
cd my-blog
pnpm install
pnpm dev
```

### 手动安装

```bash
pnpm add vitepress@2.0.0-alpha.20 vue vitepress-theme-vuejsblog
```
